## Other marks

In this vault's flavor, any character between the brackets counts as a
mark:

- [/] Half done
- [-] Cancelled
- [?] Not sure yet

## Finding tasks

Search with `task:""` for every task in the vault, `task-todo:read` for the
open tasks that mention reading, or `task-done:install` for a finished one. The [[Search queries]] note keeps such
a search inside a note.
