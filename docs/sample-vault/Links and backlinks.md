# Links and backlinks

Notes link to each other with double brackets. Back to [[Welcome]].

## Kinds of links

- A note by name: [[Math]]
- The same, with other text: [[Math|the page about formulas]]
- A heading in another note: [[Callouts#Folding]]
- A heading in this note: [[#Backlinks]]
- A block in another note: [[Tasks#^weekend]]
- A standard Markdown link works too: [code blocks](Code.md)
- A web address opens in your browser: https://example.org
- A link to a note that does not exist yet: [[Ideas for later]]. Follow it
  and Glyphvane offers to create it.

## Blocks

Any paragraph or list item can get an ID by ending it with a caret and a
name. Other notes can then link to it, or embed it, without depending on the
headings around it. ^about-blocks

## Backlinks

Open the right panel (View ▸ Toggle right panel). **Backlinks** lists every
note that links to the one you are reading, with the line around each link.
This note is linked from [[Welcome]], [[Embeds]], [[Tasks]] and
[[Canvas]], among others; check that the panel agrees.

**Unlinked mentions** lists places where another note names this one in
plain text, without a link. The [[Tables]] note mentions Welcome that way;
open Welcome and press **Link** next to the mention.
