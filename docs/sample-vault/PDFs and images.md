# PDFs and images

Attachments live in the `attachments` folder of this vault, but any folder
works: an embed finds a file by its name. Back to [[Welcome]].

## Images

![[weathervane.svg|160]]

Embed an image with `![[name.svg]]`, and give a width after a pipe to scale
it. In the Reading view, click the image to open it in the image viewer.

## PDFs

An embedded PDF shows a card that opens it in the PDF viewer:

![[sample.pdf]]

A link can open a given page: [[sample.pdf#page=2|page 2 of the sample]].
In the viewer, try selecting text, **Ctrl+F** to find a word and **Ctrl+G**
to go to a page.
