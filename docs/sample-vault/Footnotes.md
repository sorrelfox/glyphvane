# Footnotes

A footnote reference is a caret and a label in brackets.[^wind] The notes
themselves are listed at the end of the page, numbered in the order they
are first used.[^order] A short note can also be written inline.^[Like
this one, right where it applies.]

Go ▸ Go to footnote or back jumps between a reference and its note.

[^wind]: The label can be a word or a number; readers only see the number.
[^order]: This one was used second, so it is number 2.
